# Portfolio · Trần Quang Phúc

Portfolio cá nhân (React + Vite + Tailwind v4), mobile-first. Dự án nổi bật: [FreeCareerPath](https://freecareerpath.com).

- Sửa nội dung: `src/data/profile.js` (điền `url` cho TikTok/YouTube/Facebook/Beacons khi có kênh).
- Chạy local: `npm install && npm run dev`
- Deploy: Netlify (`netlify.toml`), build `npm run build`, publish `dist`.
